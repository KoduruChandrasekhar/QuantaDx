# QuantaDx

Hybrid quantum-classical AI for early disease detection.

| Folder | Contents |
|---|---|
| [`frontend/`](frontend/) | React + TypeScript web app (Vite) — see [`frontend/README.md`](frontend/README.md) |

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

## Deploy on Vercel

Import the repository in Vercel and set **Root Directory** to `frontend` (Project → Settings → General).
Everything else is configured in [`frontend/vercel.json`](frontend/vercel.json).
